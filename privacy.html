개인정보 처리방침

시행일: 2026년 11월 13일

Hermes Ledger(이하 "본 도구")는 운영자 본인 한 명이 사용하는 개인용 도구입니다. 본 도구는 이용자의 개인정보를 판매·공유·광고에 사용하지 않습니다.

1. 수집하는 정보

  • 카드 사용 알림 문자를 전달한 이메일의 내용(승인 일시, 금액, 가맹점, 결제 방식)
  • 위 내용을 정리해 저장한 스프레드시트 데이터
  • 구글 계정 인증을 위한 OAuth 접근 토큰과 갱신 토큰

2. 이용 목적

가계부 기록과 월별 지출 집계. 그 외 목적으로 사용하지 않습니다.

3. 저장 위치

데이터는 운영자 소유의 구글 계정(스프레드시트 및 메일함)과 운영자의 개인 서버에만 저장됩니다. 제3자 서버로 전송하지 않습니다.

4. 제3자 제공

제공하지 않습니다. 광고 목적으로 사용하지 않으며, 어떤 외부 업체에도 판매하지 않습니다.

5. 구글 API 사용에 관한 고지

본 도구는 구글 API로부터 받은 정보를 다음 용도로만 사용합니다.

  • 사용자가 직접 전달한 카드 사용 알림 메일을 읽어 가계부에 기록하는 용도
  • 사용자 소유의 스프레드시트에 해당 기록을 작성하고 집계하는 용도

구글 API에서 받은 데이터를 광고 목적으로 사용하지 않으며, 제3자에게 판매·양도하지 않습니다. 사람이 읽는 것을 금지하지 않으며, 일반적인 앱 개선 목적으로도 사용하지 않습니다. 본 도구의 사용은 구글 API 서비스 사용자 데이터 정책을 준수합니다.

6. 보관 기간과 삭제

가계부 기록은 운영자가 직접 삭제할 때까지 보관됩니다. 권한을 회수하면 본 도구는 더 이상 계정에 접근할 수 없습니다. 회수 방법: 구글 계정 → 보안 → 타사 앱 및 서비스 → 본 도구 선택 → 액세스 삭제.

7. 이용자의 권리

언제든지 접근 권한을 회수할 수 있고, 저장된 데이터를 직접 열람·수정·삭제할 수 있습니다.

8. 문의

개인정보 관련 문의는 운영자 이메일로 받습니다.

본 방침은 변경 시 이 페이지에 게시됩니다.
